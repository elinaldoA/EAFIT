# Kit de lançamento: EAFIT Run (corrida)

## AGORA: pré-cadastro e suspense (até 1º/12, 10h)

**Regra de ouro:** até o lançamento o Run **não mostra funcionalidades nem telas**. Só suspense e o convite para
a lista de espera. Não diga que "já dá para usar", não use "Chegou" nem "Comece agora" antes de 1º/12.
O material "Em breve" mais abaixo mostra funções do app e **não deve ser enviado**; vale o desta seção.

### 1. O link (o mais importante)

`https://eafit.com.br/corrida/?origem=NOME#avise-me`

Troque `NOME` por uma palavra sua, só letras minúsculas, números, `-` ou `_` (até 40). O painel
(**Acompanhamento → Pré-cadastro do Run**) mostra quantas pessoas se inscreveram por cada origem.

| Quem | Link |
|---|---|
| Instagram da marca | `https://eafit.com.br/corrida/?origem=instagram#avise-me` |
| TikTok da marca | `https://eafit.com.br/corrida/?origem=tiktok#avise-me` |
| YouTube da marca | `https://eafit.com.br/corrida/?origem=youtube#avise-me` |
| Facebook da marca | `https://eafit.com.br/corrida/?origem=facebook#avise-me` |
| WhatsApp (transmissão) | `https://eafit.com.br/corrida/?origem=whatsapp#avise-me` |
| Parceiro / influenciador | `https://eafit.com.br/corrida/?origem=nomedoparceiro#avise-me` |

A página mostra uma contagem regressiva até **1º de dezembro, às 10h (Brasília)** e o formulário (só e-mail).
Quem se inscreve **não cria conta nem libera o módulo**: só entra na lista para ser avisado.

### 2. Textos de bio

- **Instagram (até 150 caracteres):** `🏃 Novidade para quem corre: 1º/12. Entre na lista de espera ⬇️`
- **TikTok:** `Algo novo para quem ama correr chega em 1º/12 🏃 Lista de espera no link`
- **YouTube (descrição do canal):** `Dia 1º de dezembro tem novidade no EAFIT para quem ama correr. Entre na lista de espera: <link>`
- **Facebook (Sobre):** `Novidade para quem corre no dia 1º de dezembro. Entre na lista de espera: <link>`
- **WhatsApp (status ou transmissão):** `Você corre? Dia 1º de dezembro tem novidade no EAFIT. Entre na lista de espera e seja avisado: <link>`
